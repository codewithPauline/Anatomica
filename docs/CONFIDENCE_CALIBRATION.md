# Confidence-Calibrated Clinical Reasoning

Confidence-calibrated reasoning was introduced in **Anatomica v0.4.0** to add a metacognitive signal to localization practice.

## Purpose

Accuracy alone does not distinguish between:

- an answer the learner knew with confidence,
- a correct answer the learner nearly guessed,
- an uncertain mistake, and
- a confidently incorrect localization.

Anatomica therefore asks the learner to rate confidence before submitting each localization response.

The available ratings are:

- **Unsure** — the learner is not confident in the localization,
- **Moderate** — the learner thinks the localization fits, and
- **High** — the learner would commit to the localization.

These are self-ratings, not probabilities generated by Anatomica.

## Challenge workflow

A localization challenge now requires three inputs:

1. choose the peripheral nerve,
2. choose the lesion level, and
3. rate confidence.

The Submit button remains disabled until all three are selected.

Confidence does **not** change whether the answer is scored correct or incorrect. It adds context to the response after scoring.

## Feedback semantics

After submission, Anatomica combines correctness and self-rated confidence into descriptive feedback.

Examples include:

- **correct + high confidence** — reinforce with alternate presentations,
- **incorrect + high confidence** — high-confidence miss; revisit the discriminating clue,
- **correct + unsure** — correct but uncertain; reinforce the localization rule,
- **incorrect + unsure** — uncertain miss; review the explanation and compare nearby lesions.

These labels are study guidance only. They are not a diagnostic judgment or validated measure of clinical competence.

## Persistent storage

Confidence is stored with the challenge result in the existing browser-local learner-progress record.

Each stored result can now include:

- `challengeId`,
- `nerveId`,
- `levelId`,
- `correct`, and
- `confidence` (`low`, `medium`, or `high`).

Older saved sessions without confidence remain valid. Confidence analytics simply ignore unrated historical responses.

No account, backend learner profile, or cloud synchronization is introduced by this feature.

## Mastery Dashboard

The Mastery Dashboard includes a **Confidence calibration** section showing:

- number of rated responses,
- accuracy among high-confidence responses,
- count of high-confidence misses,
- count of correct responses made while unsure, and
- attempts / accuracy for Unsure, Moderate, and High confidence bands.

The dashboard intentionally reports observed patterns rather than assigning a proprietary calibration score.

## Why high-confidence misses matter

A high-confidence incorrect answer can indicate that a learner has a stable but incorrect distinction between two lesion patterns. Anatomica surfaces these events because they are useful candidates for Targeted Remediation and spaced review.

This does not mean every high-confidence miss reflects a misconception. Small sample sizes, ambiguous memory, or ordinary mistakes can produce the same pattern.

## Validation

`src/learning/confidenceCalibration.js` contains the pure confidence-summary logic.

`scripts/validate_confidence_calibration.mjs` checks:

- accepted confidence levels,
- label normalization,
- accuracy by confidence band,
- high-confidence miss counting,
- correct-while-unsure counting,
- feedback semantics, and
- empty / legacy progress behavior.

The existing learner-progress validator also verifies that valid confidence values persist and unsupported values are stored as `null`.

CI runs the confidence validator through `npm run validate:confidence`.

## Limitations

The current confidence ratings are ordinal categories, not calibrated numeric probabilities. Anatomica therefore does not calculate Brier scores, expected-calibration error, or other probability-calibration metrics.

Confidence summaries are descriptive and depend on the learner providing meaningful self-ratings. They should not be interpreted as certification of knowledge, examination readiness, or clinical performance.
